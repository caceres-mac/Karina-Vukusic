# Karina Vukusic - Sitio Web Profesional

## Descripción
Sitio web profesional para Karina Vukusic, especialista en crianza y prevención en entornos digitales. El sitio presenta sus servicios, publicaciones y novedades dirigidos a docentes y familias.

## Cómo ver el sitio

### Opción 1: Abrir directamente
1. Haz doble clic en el archivo `index.html`
2. Se abrirá en tu navegador predeterminado

### Opción 2: Usar un servidor local (recomendado)
Si tienes Node.js instalado:
```bash
npx http-server -p 8000
```
Luego visita: http://localhost:8000

Si tienes Python instalado:
```bash
python -m http.server 8000
```
Luego visita: http://localhost:8000

### Opción 3: Para compartir con otras personas

#### Usando Netlify (recomendado - gratis)
1. Ve a https://netlify.com
2. Crea una cuenta gratuita
3. Arrastra la carpeta del proyecto a la sección de deploy
4. Obtendrás un link público para compartir

#### Usando GitHub Pages
1. Sube los archivos a un repositorio de GitHub
2. En Settings > Pages, activa GitHub Pages
3. Obtendrás un link público

#### Usando Vercel
1. Ve a https://vercel.com
2. Importa tu proyecto desde GitHub o sube los archivos
3. Obtendrás un link público

## Personalización
Para personalizar el sitio con tu información real:
1. Reemplaza el texto en `index.html` con tu información
2. Actualiza los colores en `styles.css` si es necesario
3. Agrega tu foto real reemplazando el placeholder
4. Configura el formulario de contacto con tu email
